Run the repeatable baseline-to-scaffold recovery pattern: discover active features for the baseline, scaffold steps, final probe, and controls; identify features recruited by the scaffold but absent from the baseline; optionally steer the strongest candidate; and return a bounded confidence recommendation. Use this when the question is whether scaffolding is recruiting latent structure rather than merely adding answer words. Treat the result as evidence for later judgment, not as an automatic proof of hidden-information recovery.
