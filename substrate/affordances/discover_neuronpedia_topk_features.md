Discover which Neuronpedia SAE features activate for each token in a baseline or scaffold text. Use this before choosing a feature by hand when the question is whether a scaffold recruited latent structure: compare baseline, scaffold, and control texts, then select candidate features for single-feature activation and steering probes. Treat discovered features as hypotheses, not as interpretations until their explanations, activations, steering effects, and controls converge.
