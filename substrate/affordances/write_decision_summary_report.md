Write a concise Markdown report for each fund action decision. Use this after recording a buy, sell, hold, trim, add, reject, watch, or intentional cash posture. The report should explain how the practitioner came to the decision: live evidence used, market regime interpretation, stock-type fit, thesis basis, risk basis, the action recorded, expected portfolio effect, open questions, and next review triggers.
