Rename a Friction's kind as part of smoothing. The Judge names a Friction to give it form, but that name is provisional; the Smoother considers it and, when a name that already carries gravity fits better, condenses the provisional name toward it (optionally re-wording the content to match). Consult read_friction_kinds first so the rename moves toward the canonical vocabulary rather than minting another one-off. The rename is recorded as a step, so the old→new naming is preserved on the trail. Renaming is not required: leave a name that already fits.
