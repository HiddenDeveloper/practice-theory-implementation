name: Respond to a calendar invitation

Set the user's attendee response on a live Google Calendar event: accepted, declined, tentative, or needsAction. This writes to the calendar and may notify others depending on `send_updates`. Use only after the user has explicitly authorized the event id, attendee email, response status, and notification stance in the current enactment.
