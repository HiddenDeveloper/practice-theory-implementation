Read local operational state for situated arrival: OTEL export configuration, queue/backlog counts and when they started, recent dispatch usage, token/cache counts, latency aggregates, and current operational issues. This is a read-only affordance for context; it does not restart services, clear queues, mark work handled, or change substrate.
