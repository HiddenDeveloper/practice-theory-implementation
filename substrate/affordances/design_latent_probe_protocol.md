Design the evidence protocol for a latent-knowledge probe before asking the target model: name the model, mechanistic surfaces, target question family, known/unknown/planted controls, intervention plan, stopping conditions, and gaps. Prefer the currently reachable free/open mechanistic surfaces: Neuronpedia for public SAE feature evidence, NDIF/NNsight for remote open-model internals when access is available, and TransformerLens/SAELens when the model or SAE can be loaded locally.
