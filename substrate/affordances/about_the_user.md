Consult the full user-engagement context the apprenticeship carries across practices and sessions, returned together as one aggregated canonical-spine read: user profile, self-model, and shared operating context. Use this at engagement bootstrap when you would otherwise issue separate read_non_episodic_memory calls for context, self, user/profile, or a self-name query such as AIlumina; this single read already contains the canonical landing nodes those calls are usually trying to assemble. This static read orients the practitioner, but it is not by itself situated arrival with the user: when the work calls for companionship, currentness, or what has changed since the canonical spine, pair it with an episodic recall or a relevant non-episodic memory read, inspect what that returned, and let that grounding shape the next move rather than closing on the canonical dossier alone. Reach for an individual non-episodic memory read only when you deliberately need one node re-read for freshness, a specific id/filter, semantic lookup beyond the canonical spine, or a richer arrival basis; to learn what is new since orientation, prefer the recall affordances rather than re-pulling these static landing nodes.
