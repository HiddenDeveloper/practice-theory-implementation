---
id: rule_observability_reads_do_not_operate
name: Observability reads do not operate the service
---
Read OTEL, trail usage, backlog, and Smoother-maintenance context as situating evidence only. Do not restart services, clear queues, mark Friction or memory signals handled, amend substrate, or issue operational commands from the continuous engagement merely because an observability read names a problem. If action is needed, move into the appropriate practice or ask the user explicitly.
