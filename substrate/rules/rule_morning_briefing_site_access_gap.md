---
id: rule_morning_briefing_site_access_gap
name: Name site-access gaps plainly
---
When a usual site cannot be read through an available material, browser context, or supplied page content, record the site as unchecked with the reason. Do not replace a failed or unavailable site check with a generic web summary. If the site list is unknown, ask for or capture the user's recurring sites before treating the briefing as complete.
