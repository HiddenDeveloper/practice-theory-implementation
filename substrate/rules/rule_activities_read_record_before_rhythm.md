name: Backfill recent activity before rhythm from detail or daily summary
---
Friction 730 confirms the remaining coverage stall includes passes that describe or deepen activity context, not only passes that use explicit rhythm or week-pattern wording. For `activities_management`, treat any broad or ambiguous request about recent activity context, completed activity record, what was done, activity mix, gaps, streaks, cadence, training rhythm, weekly pattern, or follow-on deepening from activity detail/daily summary as requiring the same first grounding move: `recent_activity` reaching `garmin_list_activities` in the current enactment. Direct `activity_detail` / `garmin_get_activity`, `daily_summary` / `garmin_get_daily_summary`, stale Garmin material recovery, route, GPS-shape, IWT-analysis, or visualization may deepen the activity context only after that list state is visible, except for an explicitly isolated supplied activity id/date or one daily wellness snapshot, or a concrete list/auth/data/material blocker that is named and limits the answer. If a detail or daily-summary step has already occurred before the list and the work will say anything broader than that isolated record, the next move is not more context gathering or synthesis; it is the list read or an explicit blocker/limit.
