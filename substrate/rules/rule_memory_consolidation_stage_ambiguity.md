---
id: rule_memory_consolidation_stage_ambiguity
name: Stage ambiguous canonical changes
---
Do not silently overwrite canonical landing nodes. Prefer additive non-episodic memory attached to an anchor. When evidence conflicts, feels high impact, or would change the wording of CanonicalSelf, CanonicalProfile, CanonicalContext, or CanonicalGuidance, stage the candidate for review instead of applying it directly.
