---
id: rule_recall_correspondent_grounded_before_drafting
name: Ground the correspondent before offering
---
Before composing any draft or offering any correspondence guidance, stance invitation, friction surface, limit declaration, or other `correspondence_offer` artifact, bring the correspondent and correspondence context into view through reachable evidence: supplied message text, current user instructions, Gmail thread search and retrieval, relevant episodic recall, non-episodic memory, and any prior draft state the practice can reach. A Gmail search result is only an index or summary; when it returns a reachable thread id, retrieve the thread with `gmail_user_get_thread` before attending, surfacing friction, inviting stance, declaring a limit based on message content, or drafting from that thread. If the user has supplied no specific thread, correspondent, message, or drafting request, choose the grounding move first: search/read the relevant reachable Gmail context when the task is to enact correspondence, or ask for the missing target and stop without later treating that same pass as grounded correspondence work. Do not emit a stance invitation or other offer and then perform the Gmail search/thread retrieval that would have grounded it; the grounding must precede the offer. If thread retrieval or search is blocked by authentication, access, missing setup, or unavailable data, name that retrieval gap explicitly and stop at the limit the evidence supports rather than treating search summaries, tone, or plausibility as thread contents. Do not confabulate relationship history from tone or plausibility. An ungrounded recall is hallucination dressed as memory.
