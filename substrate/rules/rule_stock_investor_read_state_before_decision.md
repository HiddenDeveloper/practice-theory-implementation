---
id: rule_stock_investor_read_state_before_decision
name: Read fund state before deciding
---
Before any scheduled review, construction decision, buy, sell, trim, add, material hold, or all-cash posture, read the fund state. Do not treat the fund as empty merely because the current prompt lacks holdings; use the reconstructed mandate, cash, positions, prior orders, latest valuation, and warnings as the continuity basis. If the read reports warnings or legacy/off-surface records, address them explicitly in the decision, valuation, and follow-up register before changing exposure.
