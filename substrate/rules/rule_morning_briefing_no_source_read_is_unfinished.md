---
id: rule_morning_briefing_no_source_read_is_unfinished
name: No source read means the briefing has not started
---
For `morning_briefing`, an enactment that has not yet recorded `read_user_email` / `gmail_user_search_threads` and `read_morning_site_list` / `read_morning_briefing_sites`, or a concrete access, auth, configuration, data, or material blocker for each missing source, is still before the briefing's grounding threshold. Do not treat site-list-only work, browser site checks, invalid URL gaps, live snapshots, supplied context, source interpretation, handoff, or final prose as a partial substitute for this threshold. The first incomplete source gate encountered must become the immediate next move: read unread Gmail first, then the configured site list; if either cannot be reached, record that exact blocker and limit the briefing as not fully grounded. Friction 668 confirms this rule is needed because recent evaluated morning-briefing passes still omitted `gmail_user_search_threads`, and two also omitted `read_morning_briefing_sites`, even though the practice description already named both recurring source reads.

Friction 672 confirms the same quality signal remains unsatisfied across the next evaluated three-pass window: unread Gmail was absent in every pass and the configured recurring site-list read was absent in two passes, with no visible concrete blockers for the missing source reads. Treat this as a stop condition, not as another reminder. At the start of every `morning_briefing` pass, before any source interpretation, site check, live snapshot, action/watch/routine grouping, handoff, or final answer, the practitioner must create the two source-read trail facts in order: `read_user_email` reaching `gmail_user_search_threads` for unread mail, then `read_morning_site_list` reaching `read_morning_briefing_sites` for the configured recurring sites. If either read is impossible, the pass may only continue by recording the exact source surface and concrete access/auth/configuration/data/material blocker; otherwise the only valid next move is the missing read, and closure must say the briefing could not be fully grounded rather than presenting a routine orientation.

Friction 685 confirms the stop condition still failed in the next evaluated window: all three recent `morning_briefing` passes lacked `read_user_email` / `gmail_user_search_threads`, and two also lacked `read_morning_site_list` / `read_morning_briefing_sites`, with no concrete source blocker visible. Future morning-briefing work must not treat the user's prompt, supplied context, a site-list-only read, browser check, live snapshot, or final prose as the beginning of the briefing. The first visible practice move must be the unread Gmail source read, or a concrete Gmail access/auth/data/material blocker; only after that may the configured site-list read or its concrete blocker follow. If a pass reaches any other morning-briefing step while either recurring source fact is absent, stop immediately and backfill the missing source read before continuing. If backfill is impossible, close only by naming the exact missing source and saying the briefing did not reach its grounding threshold.

Friction 697 confirms this coverage failure persisted in the next evaluated window even after the bundle description and neighboring affordance guidance named the two source reads: all three recent `morning_briefing` passes omitted `read_user_email` / `gmail_user_search_threads`, and two also omitted `read_morning_site_list` / `read_morning_briefing_sites`, with no concrete blocker recorded for the missing sources. The next `morning_briefing` pass must therefore treat the source-read pair as the first work product, not a preface: before any site check, live market or news snapshot, supplied-source interpretation, action/watch/routine grouping, handoff, final answer, or assembly check, the trail must already show unread Gmail via `read_user_email` / `gmail_user_search_threads` followed by the configured site list via `read_morning_site_list` / `read_morning_briefing_sites`, or a concrete blocker for each absent source. If the first visible move is anything else, stop immediately, backfill unread Gmail first and the configured site list second, or close only by naming the exact source surface that prevented a fully grounded briefing.
