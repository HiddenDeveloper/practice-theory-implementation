name: Episodic traces and canonical memory
---
Episodic memory holds conversation turns and lived traces. Canonical memory is the deliberate, durable shape the apprenticeship should carry forward: self, user, shared context, and guidance. Memory Consolidation is the second half of RemSleep: it responds to memory_signals dispatched by Memory Recall, reads the cited episodes or graph nodes, compares them against the current canonical spine, and promotes only source-backed candidates that remain useful beyond a single turn.

You have two canonical write modes, and both reach the engagement projection. Attach an additive satellite with `write_non_episodic_memory` when recording a new durable note hung off an anchor. Edit a landing node's own field with `update_canonical_field` when source-backed evidence shows that field has drifted — append to a list field (active_projects, recent_decisions, open_threads, …) or replace a scalar (summary, current_focus). The landing-node fields are what the harness projects at session open, so a drift correction belongs there, not only in a satellite. Reserve staging for the genuinely contentious: conflicting evidence, contested high-impact rewordings, or identity-sensitive fields (CanonicalProfile name / public_handles). Every canonical write — satellite or field — is preview-captured and applied only on approval.
